# NOCTURNE Loader

Отдельное приложение для Windows: вход по аккаунту, проверка подписки и запуск файла чита.
Файл может лежать локально (`mode=local`, удобно для теста) или на сервере лицензий
(`mode=server`, путь и файл не видны пользователю).

```
launcher/
├─ src/main.cpp              исходник лоадера (Win32, без сторонних библиотек)
├─ build.bat                 сборка MSVC или MinGW-w64
├─ loader.ini.example        пример настроек
└─ server/                   сервер лицензий на Node.js
   ├─ server.js
   ├─ db.json                создаётся автоматически
   └─ private/               сюда кладётся файл сборки (не отдаётся напрямую)
```

## Сборка

Нужен **MSVC** (Developer Command Prompt) или **MinGW-w64**.

```bat
cd launcher
build.bat
```

На выходе — `NocturneLoader.exe` (64-бит). При первом запуске рядом создаётся `loader.ini`.

## Настройка

```ini
[app]
mode=local
api_url=http://127.0.0.1:8090
cheat_path=C:\NOCTURNE\cheat.exe
cheat_args=
save_dir=%LOCALAPPDATA%\NOCTURNE\build
close_after_launch=0

[demo]
login=demo
password=demo
until=2026-12-31
```

### `mode=local` — быстрый тест

Лоадер сверяет логин/пароль из секции `[demo]`, проверяет дату `until` и запускает
`cheat_path`. Сервер не нужен. Подходит, чтобы проверить интерфейс и запуск.

### `mode=server` — рабочий вариант

Лоадер:

1. отправляет логин/пароль на `/api/login`;
2. получает срок подписки и сессию;
3. по кнопке «Играть» запрашивает `/api/ticket` — сервер выдаёт **одноразовую ссылку**;
4. скачивает файл, сверяет SHA-256 и запускает его.

Путь к файлу и сам файл в лоадере не хранятся: ссылка живёт 5 минут и срабатывает один раз.
Файл лежит в `server/private/` и не отдаётся напрямую.

## Сервер лицензий

```bat
cd launcher

:: создать аккаунт на 30 дней (или указать дату: 2026-12-31)
node server\server.js adduser player1 пароль123

:: положить сборку чита в private/ и посчитать SHA-256
node server\server.js setbuild C:\builds\cheat.exe

:: запустить сервер
node server\server.js serve
```

Затем в `loader.ini`:

```ini
mode=server
api_url=http://127.0.0.1:8090
```

Подробнее — в `server/README.md`.

## Важно про защиту

- Лоадер — клиентское приложение. Его можно пропатчить, а скачанный файл остаётся на диске.
  Полностью «не украсть» файл нельзя; можно только усложнить жизнь.
- Реально помогают: выдача файла только по одноразовой ссылке после проверки подписки
  (уже реализовано), HTTPS, привязка к HWID, персональные водяные знаки в сборке,
  подпись кода и обфускация.
- Никогда не кладите файл чита в открытый репозиторий и не публикуйте прямую ссылку на него.
- Пароли в `db.json` хешируются SHA-256 с солью — для продакшена замените на bcrypt/argon2.
- `demo`/`demo` создаётся только при первой инициализации базы. Удалите этот аккаунт перед публикацией.

## Сайт

Кнопка «Скачать лоадер» в кабинете ведёт на `assets/NocturneLoader.exe` (демо-сборка без подписи). После пересборки положите новый exe туда же. Вход в панель по ключам — ссылка «Панель управления» в боковом меню сайта. При публикации сервера лицензий укажите его адрес в `loader.ini` (`api_url`).
