# NOCTURNE Owner Key

Маленькое приложение для Windows: одно окно, одна кнопка — **«Сгенерировать код»**.
По нажатию появляется одноразовый код входа владельца вида `OWN-ABCD-EFGH`.

Код действует **5 минут**, сгорает после первого успешного входа и заменяется новым,
если нажать кнопку ещё раз. Кнопка «Скопировать» кладёт код в буфер обмена.

## Зачем это

Админ-панель (`admin.html`, вкладка «Владелец») пускает владельца **только по одноразовому коду**
из этого приложения — пароля у владельца больше нет. Панель заодно показывает, на связи ли
приложение, и подсказывает, если его нужно запустить.

Код никуда не уходит: приложение поднимает локальный HTTP-сервер на `127.0.0.1:47830`,
админ-панель на этом же компьютере отправляет код на проверку, приложение подтверждает
его и сразу сжигает. Через сеть сам код не передаётся — доступен только статус
(есть ли активный код и сколько ему осталось).

## Сборка

```bat
cd launcher\owner-app
build.bat
```

Нужен MSVC (x64 Native Tools) или MinGW-w64. Готовый файл: `NocturneOwnerKey.exe`.
Без зависимостей и установщика: один exe рядом с панелью.

Кросс-сборка под Windows из Linux (zig):

```bash
zig c++ -target x86_64-windows-gnu -std=c++17 -O2 -municode \
    -Wl,--subsystem,windows src/main.cpp -o build/NocturneOwnerKey.exe \
    -lws2_32 -lbcrypt -luser32 -lgdi32 -lshell32
```

Тестовая сборка под Linux (консольный режим, без GUI — удобно проверять API):

```bash
g++ -std=c++17 -O2 -pthread src/main.cpp -o ownerkey
NC_OWNER_PORT=47930 ./ownerkey
```

## Как пользоваться

1. Запустите `NocturneOwnerKey.exe`.
2. Нажмите **«Сгенерировать код»**, при желании — «Скопировать».
3. Откройте `admin.html`, вкладка **«Владелец»**: там сразу поле «Одноразовый код» и строка
   «Приложение на связи · код готов…» (или «Приложение не запущено»).
4. Вставьте код и нажмите «Войти по коду».

Порт можно изменить переменной `NC_OWNER_PORT`, время жизни кода — `NC_OWNER_TTL`
(секунды, только для проверки поведения по истечении). — тогда тот же адрес нужно указать
в панели: `<script>window.NC_OWNER_APP_URL = 'http://127.0.0.1:47930';</script>`.

## API (только локально)

```
GET  /api/owner/status
{"ok":true,"app":"nocturne-owner-key","version":"1.0.0","port":47830,
 "hasCode":true,"expiresAt":1794655685725,"ttl":300}

POST /api/owner/verify   {"code":"OWN-ABCD-EFGH"}
{"ok":true}                       — код верный, сгорел
{"ok":false,"error":"Неверный код. Осталось попыток: 9."}
```

Ограничения: 10 попыток на код, 5 минут жизни, сервер слушает только `127.0.0.1`
и отдаёт `Access-Control-Allow-Origin: *`, чтобы панель могла обратиться с localhost.

## Безопасность — честно

- Код создаёт любой, кто запустил приложение на этом компьютере. Пароля владельца нет,
  поэтому без запущенного приложения войти нельзя: это защита от подглядывания и от входа
  «по памяти», а не от человека за тем же ПК.
- Приложение и панель должны быть на одной машине: сервер слушает loopback.
- Если сайт открыт по HTTPS, браузер заблокирует запрос к `http://127.0.0.1`
  (mixed content). Открывайте панель локально по `http://`.
- Для настоящей защиты нужен backend: коды должны выдавать и проверять серверные
  ключи, а не процесс на компьютере владельца.
