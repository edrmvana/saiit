# NOCTURNE — игровая платформа

NOCTURNE — статический веб-проект на HTML, CSS и JavaScript. В архив входят главная страница с каталогом, личный кабинет, локальная демо-авторизация, управление подписками и ролями, административная панель, а также отдельная настольная утилита Admin Desk.

## Запуск сайта

1. Распакуйте архив целиком — папка `assets` должна оставаться рядом с HTML-файлами.
2. Откройте `index.html` в браузере. Для стабильной работы рекомендуется локальный HTTP-сервер или обычный веб-хостинг.
3. Админ-панель открывается файлом `admin.html` из той же папки.

Основные файлы:

| Файл | Назначение |
|---|---|
| `index.html` | Главная страница и разметка личного кабинета |
| `style.css` | Основные стили сайта и адаптивная сетка |
| `app.js` | Каталог, навигация и интерфейсные действия |
| `account.js` | Демо-аккаунты, профиль, подписки и активация ключей |
| `admin.html` | Локальная административная панель |
| `product-page.js`, `product-page.css` | Страницы и карточки продуктов |
| `roles.js`, `roles.css` | Косметические роли игроков |
| `staff-access.js`, `staff-access.css` | Вход персонала по ключам, роли и права в админ-панели |
| `launcher/` | Отдельный Windows-лоадер и мини-сервер лицензий |
| `auth-transition.js` | Переходы авторизации |
| `scroll-reveal.js`, `scroll-reveal.css` | Появление элементов при прокрутке |
| `assets/` | Изображения, логотип `nc_logo.webp`, иконка `blackhole.webp`, фон `space-bg.webp`, лоадер `NocturneLoader.exe` |
| `admin-desktop-tool/` | Отдельное настольное приложение администратора |

## Что важно знать перед публикацией
**Про изображения.** Фон главной страницы — `assets/space-bg.webp`, на телефоне — `assets/ton618-hero-mobile.webp`, экран входа в админ-панель — `assets/ton618-hero.webp`. Логотип — `assets/nc_logo.webp`, иконка косметики — `assets/blackhole.webp`.


**Текущая версия — локальный демонстрационный прототип, а не готовая серверная система.** Аккаунты, ключи, промокоды, сообщения и переключатель сервера хранятся в `localStorage` браузера. Они не синхронизируются между устройствами, браузерами или разными адресами сайта.

Пароль, встроенный в `admin.html`, находится в клиентском коде и может быть прочитан посетителем. Он не является настоящей защитой. Не размещайте текущую админ-панель в открытом интернете и не используйте её для реальных платежей, персональных данных или критичных операций.

Для публичного запуска необходим backend: серверная авторизация и роли, база данных, серверная проверка ключей и промокодов, API для сайта и Admin Desk, журналирование на сервере, HTTPS, резервное копирование и проверка прав на каждом запросе. Одного изменения HTML/JavaScript для этого недостаточно.

## Доступ персонала (роли и ключи)

В админ-панели есть отдельный вход для сотрудников. Владелец входит по паролю, остальные — по ключу доступа.

1. Владелец открывает `admin.html`, вкладку «Владелец», и вводит демо-пароль `qwerty123123`.
2. В разделе **«Сотрудники и доступы»** он создаёт ключ: выбирает роль, пишет заметку и передаёт ключ формата `STF-XXXX-XXXX` сотруднику.
3. Сотрудник открывает `admin.html`, вкладку «Сотрудник», вводит ключ и при первой активации — своё имя. Ключ привязывается к имени и действует до отзыва.
4. Кнопка «Отозвать» закрывает вход по ключу. В журнале действий теперь видно, кто выполнил операцию.

Владелец может выдать ключ любой роли; старший админ — только младшего модератора и модератора. Владельца ключом выдать нельзя — только вход по паролю.

| Роль | Что доступно в панели |
|---|---|
| Младший модератор | тикеты игроков: отвечать, брать в работу и закрывать |
| Модератор | тикеты, чат (просмотр и удаление сообщений), список игроков |
| Админ | игроки (баланс, пароль, блокировка, подписка), ключи подписок, промокоды, журнал |
| Старший админ | всё выше + сервер, массовые операции с подписками, резервные копии, выдача ключей младшим |
| Владелец | все разделы и все ключи |

Полная матрица прав отображается прямо в разделе «Сотрудники и доступы».

### Тикеты игроков и промокод 1FIRST

В личном кабинете на сайте появился раздел **«Тикеты»** (он же — пункт меню «Тикеты» и вкладка в кабинете). Каждое обращение игрока — отдельный тикет с историей сообщений:

- игрок пишет любое количество сообщений, видит статус «Открыт», «В работе» или «Закрыт» и имя сотрудника, который взял тикет;
- младший модератор в админ-панели видит те же тикеты, может взять тикет в работу, отвечать (сколько угодно сообщений) и закрывать/переоткрывать его;
- смена исполнителя и закрытие фиксируются системными сообщениями в тикете и в журнале действий.

Промокод `1FIRST` создаётся автоматически при первом открытии сайта или панели: скидка **20%**, действует только на первую покупку игрока. В панели промокодов он помечен как «1-я покупка»; после первой покупки игроку он больше не срабатывает.

**Ограничение демо:** ключи, сессии и проверка прав выполняются в браузере (`localStorage`). Ключ, созданный у владельца, сработает только в том же браузере, а ограничения интерфейса можно обойти через консоль. Чтобы сотрудник входил со своего устройства, нужен backend с общей базой и серверной проверкой прав на каждом запросе — это следующий шаг.

## Лоадер (отдельное приложение)

В папке `launcher/` лежит отдельное Windows-приложение: вход по аккаунту, проверка подписки и запуск файла чита. Оно не связано с `localStorage` сайта — у сервера лицензий своя база.

- `mode=local` — быстрый тест: логин/пароль и путь к файлу берутся из `loader.ini`, сервер не нужен.
- `mode=server` — рабочий вариант: лоадер проверяет аккаунт и подписку через `launcher/server/server.js`, получает одноразовую ссылку на файл, сверяет SHA-256 и только потом запускает. Путь к файлу и сам файл в лоадере не хранятся.

Сборка: откройте Developer Command Prompt (MSVC) или консоль с MinGW-w64, затем `launcher\build.bat`. Пример настроек — `launcher/loader.ini.example`.

Сервер:

```bat
cd launcher
node server\server.js adduser player1 пароль 2026-12-31
node server\server.js setbuild C:\builds\cheat.exe
node server\server.js serve
```

Кнопка «Скачать лоадер» в кабинете ведёт на `assets/NocturneLoader.exe` (демо-сборка без подписи, Windows может показать предупреждение SmartScreen). После пересборки замените файл. Вход в панель по ключам — ссылка «Панель управления» в боковом меню сайта (`admin.html`).

Подробности и ограничения — в `launcher/README.md` и `launcher/server/README.md`.

## Настольный Admin Desk

Инструкция по запуску находится в `admin-desktop-tool/README.md`. Это отдельное локальное приложение со своей базой `admin_data.json`. Оно пока **не подключено** к `localStorage` сайта и не может самостоятельно активировать или отзывать ключи на сайте.


## NOCTURNE Admin Desk — C++ edition
Новая нативная версия находится в `admin-desktop-tool-cpp/`. На Windows запустите `build.bat` из Developer Command Prompt для MSVC или MinGW-w64. Ключ входа: `qwerty123123`. Старая Python-версия оставлена в архиве как legacy.

**Ограничение:** сайт остаётся локальным статическим демо. Ключи, созданные C++ приложением, не синхронизируются с сайтом; для этого требуется backend и серверная общая база.
